# Contributing

## Start with an issue

Open an issue before writing code. Describe the problem and the alternatives you considered.
A PR without a prior issue may be closed without review.
Typo and documentation fixes do not need an issue.

## Introduce yourself

If this is your first contribution, say in the issue how you use the project.
You can also introduce yourself in the #borkdude-misc channel on [Clojurians Slack](http://clojurians.net).

## AI tools

Mention in the PR if you used AI tools to write the change.
You must understand every line, run the tests and answer review questions yourself.
PRs that look generated and unreviewed will be closed.
