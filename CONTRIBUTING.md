# Contributing

## Start with an issue

Open an issue before writing code. Describe the problem and the alternatives you considered.
A PR without a prior issue may be closed without review.
Typo and documentation fixes do not need an issue.

## Introduce yourself

If this is your first contribution, explain in the issue what your interest in this project is and why you decided to contribute to it. How are you using this project? How long have you been using it? How long have you been using Clojure? Have you contributed to other Clojure projects before?
Preferably you will come say hi and introduce yourself in the #borkdude-misc channel on [Clojurians Slack](http://clojurians.net).

## AI tools

I do not necessarily prohibit the use of AI tools, but you are expected to:

- Understand and explain every addition, deletion or change
- Add (when applicable) and run the tests
- Answer review questions yourself

PRs that look generated and unreviewed will be closed.
